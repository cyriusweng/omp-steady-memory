# steady-memory

Two small pieces that keep an OMP (Oh My Pi) agent's voice and memory stable across long conversations. The designs are borrowed from two open-source projects:

- **Hermes Agent** loads a small, hard-capped memory block at the start of every session, so the persona and what the agent knows about you never fall out of context.
- **SillyTavern** re-asserts the character's voice right before each generation (`post_history_instructions`), so long conversations don't drift.

## What's inside

- `extensions/steady-memory.mjs` — OMP extension. Before each generation it appends a hidden, static reminder of your voice rules after the last message. Static text keeps provider prefix caches valid; cost is about 110 tokens per request. Main sessions only; subagents are skipped.
- `extensions/steady-memory.txt` — the reminder text. Edit this freely; the extension reads it live.
- `models/steady-memory-models.json` — definitions for two custom OMP mental models.
- `scripts/create-models.sh` — creates or refreshes those models on a Hindsight bank.

## The two mental models

OMP's built-in mental models are curated summaries that the memory backend generates in the background and injects at session start (see `/memory mm list`). This package adds two, with mutually exclusive domains written into their source queries, so consolidation never merges your identity into your todo list or the other way round:

- `user-portrait` — who you are: stable traits, taste, values, boundaries. Excludes project state and tooling preferences.
- `working-memory` — what you're working on right now: active projects, decisions with rationale, open threads. Excludes stable personal traits.

## Install

1. Copy `extensions/steady-memory.mjs` and `extensions/steady-memory.txt` to `~/.omp/agent/extensions/`.
2. Register the extension in `~/.omp/agent/config.yml`:
   ```yaml
   extensions:
     - /Users/you/.omp/agent/extensions/steady-memory.mjs
   ```
3. Run `bash scripts/create-models.sh`. It reads your Hindsight URL, bank id and token from `HINDSIGHT_URL`, `HINDSIGHT_BANK_ID`, `HINDSIGHT_TOKEN`, or falls back to parsing `~/.omp/agent/config.yml`.
4. Start a new OMP session and check `/memory mm list`.

## Backend note

The extension works with any OMP memory backend (`off`, `local`, `hindsight`, `mnemopi`, `sharpshooter`): it only hooks prompt assembly. The mental models need the `hindsight` backend — they are records in the Hindsight server, generated by its background reflect jobs and injected as part of the `<mental_models>` block, within OMP's shared render budget (16,000 characters by default).

## Security

No secrets live in this repository. The script reads your token from the environment or your local config file. Never commit the token itself.
